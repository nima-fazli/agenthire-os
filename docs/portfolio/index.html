A focused recruiting workflow.

The application keeps organization and job context explicit. Source review, workflow changes and access management have separate responsibilities.

System design

Clear boundaries before more services.

A modular monolith owns the HTTP workflow. PostgreSQL enforces tenant relationships and concurrency invariants; workers handle bounded document processing.

INTERFACE

Browser workspace

English modules, explicit context, keyboard navigation and in-memory credentials call the authenticated API.

APPLICATION

FastAPI services

Routes resolve dependencies. Services authorize and own transactions. Repositories issue scoped SQL.

PERSISTENCE

PostgreSQL / pgvector

Composite foreign keys, row locks, durable leases and versioned source metadata preserve invariants.

Document path: API upload → private PDF volume → extraction worker → immutable chunks. Optional local Ollama models support semantic retrieval and grounded briefs.

Recovery is part of the design. Coordinated database and document snapshots are exercised through isolated restore gates. The source repository is separate from private operational backups.

Engineering tradeoffs

Decisions with practical costs.

The design favors inspectable behavior and explicit failure handling. Each boundary carries a cost that should stay visible during review.

Modular monolith

One application keeps authorization and transaction ownership close. Module boundaries and tests carry the discipline that separate services would otherwise enforce operationally.

Database-backed leases

Durable extraction jobs avoid introducing a separate broker. Lease ownership, heartbeat checks and conditional completion add database logic that requires real concurrency tests.

Grounded local models

Optional local inference reduces reliance on an external model service. Model resources, latency and output quality still need independent measurement; retrieval scores are not hiring probabilities.

Coordinated storage recovery

Database commits and filesystem writes are not one atomic transaction. Reconciliation guards and coordinated backups address ambiguous outcomes and need rehearsed restore procedures.
